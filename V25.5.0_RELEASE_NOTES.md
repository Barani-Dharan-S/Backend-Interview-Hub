# Backend Interview Hub — V25.5.0

## Progress & Mastery Layer

V25.5 adds a lightweight local progress system so the learning roadmap reflects actual study activity.

### What changed
- Added persistent browser-local progress using `localStorage`.
- Learning lessons and labs can be marked complete after the user can explain them confidently.
- Backend interview questions can be marked reviewed.
- Learning pages show completion percentage and completed-item counts for the active content track.
- The roadmap hero now shows an aggregate mastery percentage.
- Each roadmap stage shows its own mastery percentage and progress bar.
- Stage details expose reviewed/completed counts.
- Added reset-progress controls without affecting question data or routing.
- Preserved the existing V25.4 connected roadmap and V25.3 premium learning surfaces.
- Fixed `BackendRoadmap` forwarding `onView`, so learning-track stage buttons correctly navigate to their learning pages.
- No new runtime dependencies.

### Storage
Progress is stored only in the current browser under `backend-interview-progress-v1`; no backend or account sync was introduced.
