# V13.0 — Practical Engineering Labs

V13 turns the hub from primarily learning/interview content into a practical engineering training path.

## Added
- 12 Build Labs covering React + Spring Boot, REST, validation, pagination, search, JWT, errors, uploads, transactions, idempotency, observability and deployment.
- 10 Debug Labs covering browser/network failures, HTTP auth, CORS, database performance, duplicate commands, Spring errors, async races, deployment, authorization and load-related latency.
- 8 Architecture Labs showing an incremental path from a layered Spring Boot application to production-scale concerns.
- Search, L1/L2/L3 filtering, expand/collapse and interview-ready delivery remain consistent with the existing hub.

## Learning philosophy
Learn → Build → Break → Debug → Explain.

No progress/gamification system was added. TypeScript remains intentionally last in the learning progression.
