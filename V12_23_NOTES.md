# V12.23 — Full-Stack Scenarios Learning Foundations

## Purpose
V12.23 turns the Full-Stack Scenarios section into a learning-first track. Learners study the core concepts needed to reason about production scenarios before attempting the scenario cards.

## Added
- 20 guided foundation lessons covering request flow, HTTP, browser debugging, CORS, error handling, Spring request lifecycle, authentication, JWT, DTOs, transactions, idempotency, pagination, search, caching, file uploads, resilience, observability, configuration, deployment and end-to-end debugging.
- Each foundation follows the existing hub learning pattern: quick understanding, deep dive, example, interview delivery, follow-ups with direct answers, and interview traps.
- Existing 40 production scenarios and their 120 scenario-specific follow-ups are preserved.
- Existing UI structure is preserved; this is a content/learning-depth expansion rather than a visual redesign.

## Learning sequence
1. Learn First — 20 foundations
2. Production Scenarios — 40 scenarios
3. Later: scenario quiz/interview mode after the learner has studied the material
