# V25.7.0 — Smart Study Queue

## Focus
Turn the progress dashboard into an actionable study planner.

## Changes
- Added a Smart Study Queue to the Personal Study Dashboard.
- Prioritizes unfinished questions using mastery gaps, roadmap order, question level and lightweight recall signals.
- Adds unfinished lessons/labs to the same queue with sequence and weak-track signals.
- Shows a reason for why each item was selected.
- Provides direct Open actions for the relevant topic/learning track.
- Question items can be marked reviewed directly from the queue.
- Keeps the queue deterministic and fully local; no external service or dependency was added.
- Preserves existing V25.5/V25.6 progress storage and routing.
- Added responsive, light-theme and reduced-motion treatments.

## Verification
Run `npm install` and `npm run build`, then verify the queue after changing progress.
