# Backend Interview Hub — V25.4.0

## Connected Learning Roadmap

V25.4 turns the Interview Roadmap from a long list of stages into a connected learning map.

### What changed
- Reworked the roadmap hero into a premium learning-path introduction with stage, question, and learning-item metrics.
- Added a connected vertical path with numbered nodes and visual progression connectors.
- Added expandable stage details so the roadmap remains compact while still exposing subtopic-level question counts.
- Added separate visual treatment for question-bank stages and guided-learning tracks.
- Added a progressive "Show all" flow so the core backend path is visible first without hiding the complete engineering journey.
- Preserved existing navigation: stage actions open the relevant question bank or learning page; area actions continue to filter directly to a subtopic.
- Added responsive and reduced-motion behavior.
- Added light-theme treatments matching the existing V25.3 visual language.

### Engineering constraints
- No new runtime dependencies.
- Existing roadmap data and question classification remain the source of truth.
- Existing routing and page architecture remain unchanged.
