# V25.8.0 — Focused Study Sessions

## Purpose
Turn the Smart Study Queue into a distraction-free, repeatable study workflow.

## Added
- Dedicated Study Session route and sidebar entry.
- 10 / 20 / 30 minute session presets.
- Session plans built from unfinished Smart Study Queue-style content.
- One-item-at-a-time focused study workspace.
- Recall → explain → check → commit study loop.
- Mark current item as covered without losing the existing progress model.
- Direct links from session items to their full learning/question content.
- Session completion history stored locally.
- Consecutive completed study-day streak.
- Last-session summary.
- Start Focused Session action from the Smart Study Queue.
- Responsive, light-theme, and reduced-motion treatments.

## Compatibility
- No new runtime dependencies.
- Existing V25.5/V25.6/V25.7 local progress storage remains unchanged.
- Session history uses a separate localStorage key: `backend-interview-study-sessions-v1`.
- Existing routing and content data are preserved.
