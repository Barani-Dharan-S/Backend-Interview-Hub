# V25.6.0 — Personal Study Dashboard

## Focus
Turn the V25.5 progress layer into a dedicated study workspace without changing the underlying interview content.

## Added
- New `/progress` Personal Study Dashboard.
- Overall mastery summary and tracked-item totals.
- Continue Learning card that routes to the next unfinished item.
- Mastery-by-domain grid covering backend question banks and learning tracks.
- Focus Areas section for the least-complete tracked domains.
- Recent Activity section using locally stored completion timestamps.
- Reset-all-progress control.
- My Progress entry in the sidebar and dedicated header metadata.

## Progress storage
- Existing V25.5 array format is migrated automatically.
- New storage format preserves `completed` IDs and `completionTimes`.
- Completion toggles remain backward-compatible with existing learning pages.

## Design
- Linear-inspired dashboard surfaces consistent with V25.2–V25.5.
- Responsive desktop/tablet/mobile layouts.
- Light theme and reduced-motion support.
- No new runtime dependencies.

## Preserved
- Existing routes, question data, learning data, filters, completion actions, roadmap behavior, and navigation.
