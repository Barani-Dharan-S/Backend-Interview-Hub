# V25.1.0 — Linear / Modern Visual Foundation

This release establishes the visual foundation for the Interview Hub redesign without changing learning content, routing, or data behavior.

## Included
- Near-black layered background with ambient indigo lighting
- Subtle technical grid overlay
- Inter-based typography foundation
- Centralized color, radius, motion, and shadow tokens
- Glass/elevated surface treatment
- Indigo interaction states replacing the previous lime accent in the new visual layer
- Multi-layer card and CTA shadows
- Refined focus rings
- Subtle expo-out transitions
- Reduced-motion support for ambient animation
- Light-theme compatibility for the new token layer

## Intentionally unchanged
- Routing
- Learning/question data
- Lazy loading
- Existing component contracts
- Application functionality
