# V25.0 — Learning Depth & Complete Interview Roadmap

## Focus
V25 begins the learning-quality phase of the hub. The first milestone updates the Interview Roadmap so it reflects the complete learning system built through V24.5.

## Roadmap coverage
The roadmap now continues beyond the original backend sequence (through Coding) into:

- React
- JavaScript
- Full Stack Development
- Full-Stack Scenarios
- Practical Labs
- Docker
- Kubernetes
- CI/CD
- Jenkins
- GitHub Actions
- Cloud & Deployment
- End-to-End Production Engineering
- Deep Learning & Architecture
- Internal Workings
- Distributed Systems

## Principles
- UI remains intentionally unchanged except for the functional roadmap expansion.
- No scores, quizzes, pass/fail, or gamification.
- The roadmap is a learning sequence and navigation index.
- Existing backend question/subtopic behavior is preserved.
- Counts come from lightweight navigation metadata for the non-backend learning tracks.

## Next V25 milestones
- Deepen high-value lessons with mechanism, trade-offs, production behavior and troubleshooting.
- Add meaningful prerequisite and cross-stack concept connections.
- Strengthen interview delivery and follow-up reasoning.


### V25.0.1 — Runtime polish
- Added synchronous pre-React theme initialization in `index.html` to prevent first-paint theme flash.
- Added route-aware document titles and meta descriptions.
- Collapsed backend Questions/Roadmap component+data loading into a single Suspense promise to avoid a second data-loading flicker.
- Wrapped the React application in `React.StrictMode`.
