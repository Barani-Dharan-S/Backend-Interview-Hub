# Backend Interview Preparation — V8

A focused, client-side Java Backend interview preparation site for GitHub Pages.

## Included
- Structured interview roadmap with topic-level taxonomy and focused subtopics
- 494 interview questions, organized into preparation-focused subtopics
- Topic filtering: Java, Spring Boot, Microservices, SQL, JPA/Hibernate, Security, Cloud, System Design, Coding
- L1 / L2 / L3 difficulty filtering
- Search, expand all and collapse all
- Interview-oriented explanations, deep dives, examples, interview delivery and follow-ups where available
- Dark/light mode
- No accounts, database, progress tracking, mastery percentages or gamification

## Run locally
```bash
npm install
npm run dev
```

## Build for GitHub Pages
```bash
npm run build
```


## V8 Coding Improvements
- Coding questions now include complete runnable Java programs instead of one-line snippets.
- Programs include imports, `public class Main`, `main` method, sample data/input, implementation, and output-oriented demonstration.
- Coding questions are grouped into focused subtopics.
