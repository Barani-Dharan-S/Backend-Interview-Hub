# V18.0 — GitHub Actions Engineering Track

- Added 60 GitHub Actions lessons and 12 practical labs.
- Covers workflow anatomy, triggers, jobs/runners, Java/Maven/Gradle CI, React CI, artifacts, caching, Docker/GHCR, Kubernetes deployment, environments/approvals, concurrency, matrices, reusable workflows, composite actions, outputs, security, fork PRs, OIDC, dependency review, provenance, self-hosted runners, debugging, rollback, canary/blue-green and production architecture.
- Added Jenkins → GitHub Actions migration material.
- Every new lesson/lab has question-specific follow-up answers; no generic fallback answers are used.
- Added GitHub Actions route, sidebar item and header metadata.
- UI intentionally unchanged.
- TypeScript remains removed from the roadmap.
- Learning philosophy: Code → Trigger → Build → Test → Scan → Publish → Deploy → Verify → Rollback → Explain.
