# V19.0 — Cloud & Deployment Engineering

- Added 60 cloud/deployment lessons and 12 production labs.
- Covers AWS fundamentals, Regions/AZs, shared responsibility, IAM, VPC, subnets, routing, security groups/NACLs, EC2, Auto Scaling, ALB/NLB, ECR, S3/EBS/EFS, RDS/PostgreSQL, DNS/Route 53, TLS, KMS, CloudWatch, tracing, React deployment, Spring Boot deployment, blue-green/canary, GitHub Actions → AWS OIDC, EKS/ECS, workload identity, HA, graceful shutdown, performance, cost, runbooks, incident response, DR/RTO/RPO and production architecture.
- Learning flow: Code → Build → Registry → Cloud → Deploy → Observe → Recover.
- Every lesson and lab has question-specific follow-up answers.
- UI intentionally unchanged.
- TypeScript remains removed from the roadmap.
